Event Management System | Java, Spring Boot, PostgreSQL, Thymeleaf

Developed a full-stack web application using Spring Boot and Thymeleaf to streamline event scheduling and location management.

Implemented a layered MVC architecture, ensuring clean separation of concerns between business logic (Service), data access (Repository), and UI (Controller).

Engineered a persistent data layer with PostgreSQL, utilizing Spring Data JPA for efficient CRUD operations and relational mapping between Events and Locations.

Migrated legacy Servlet-based logic to modern Spring Controllers, improving code maintainability and scalability.

Designed a responsive front-end using Bootstrap 5, featuring dynamic forms and real-time validation for a seamless user experience.
